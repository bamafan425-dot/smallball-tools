# ⚾ SmallBall ToolKits

🌐 **Website: https://slipnsliders.github.io/smallball-tools/**

Free, community-made tools for [SmallBall Baseball](https://play.smallball.com), by **Slip** (slipnsliders · Discord: tetonbush).

Everything here is **read-only on SmallBall**: no tool ever plays, trains, changes lineups or saves anything for you. Your data stays in your own browser.

## Installing a browser extension (Chrome, Edge, Brave)
1. Download the kit's zip (links above, or the [downloads](downloads/) folder) and unzip it somewhere you'll keep it.
2. Open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick the unzipped folder, then refresh play.smallball.com.

To update: unzip the new version over the old folder and click ↻ reload on the kit in `chrome://extensions`.
