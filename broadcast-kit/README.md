# 📺 SmallBall Broadcast Kit

Watch-along multiview for play.smallball.com: up to four games in SmallBall's own player, a synced start,
a spoiler shield, a play-by-play booth, SmallBall Radio (Mack and Dewey) and Stream Mode (SBSN) for OBS or StreamYard.
Read-only. Full guide: [README.txt](README.txt). Booth lore sources: [LORE.md](LORE.md).
