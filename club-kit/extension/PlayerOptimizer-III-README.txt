SmallBall PlayerOptimizer III
Created by Jon2s

HOW TO INSTALL IN CHROME / EDGE / BRAVE:
1. Unzip this folder to a permanent location on your computer (e.g., Documents\SmallBall-PlayerOptimizer-III).
2. Open Chrome and go to: chrome://extensions
3. Turn ON "Developer mode" using the toggle in the top-right corner.
4. Click "Load unpacked" in the top-left corner and select the unzipped folder.

HOW TO USE:
1. Go to https://play.smallball.com and open any club you own (or refresh the page if it was already open).
2. Scroll down to LINEUP and click the blue "AUTO-OPTIMIZE" button next to SAVE.
3. Review the suggested positions and 1-9 batting order, then click the red "SAVE" button to lock it in.
